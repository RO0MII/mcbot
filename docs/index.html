Built around the bot, not the dashboard.

Everything is live from the server itself — not a mock, not a cached guess.

Live console

Chat, logins, switches and errors stream in as they happen, with a reconnecting live badge.

Real inventory

27 storage slots, hotbar, armour, off-hand and 2×2 crafting — laid out like the game, with item textures.

Player profile

The bot's real skin, health, food, XP, effects, dimension, ping, position and equipped gear in one place.

Stays online

Auto-login, auto-reconnect and a socket watchdog. If a session dies, the panel notices and rebuilds it.

Auto-eat & /afk

Eats the best food when hunger drops, and clicks the first slot of the GUI that opens after /afk.

Group commands

Pick a group, type once, and the command goes to every online bot in it — with skipped bots reported.

quick start

Online in one command.

Install once, start the panel, open port 80. The dashboard manages the bots from there.

Set DASHBOARD_PASSWORD before exposing it to the internet.

terminal
# clone and install
git clone https://github.com/RO0MII/mcbot.git
cd mcbot
npm install

# start the panel on port 80
npm start
